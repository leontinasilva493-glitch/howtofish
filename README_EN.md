# Survive Verity Wiki

This is the English project guide for the unofficial Survive Verity in Area 51 Wiki.

The project is a Next.js App Router site with static, evidence-labelled guide pages, a wiki directory, maps, entity notes, code status, updates, community links, and small player tools.

Use `npm ci`, `npm run dev`, and `npm run build` for local development and production verification. Set `NEXT_PUBLIC_SITE_URL` before deployment.
